Perguntas frequentes

Tire as suas dúvidas

Preciso de internet para usar?

Não. O programa abre no navegador do seu computador e funciona offline. A internet é necessária apenas para baixar o arquivo.

Em quais computadores funciona?

Foi feito para abrir nos navegadores modernos (Chrome, Edge e Firefox) em Windows, Mac e Linux. Não precisa instalar nada.

Meus dados ficam seguros?

Os dados ficam só no seu computador, dentro do navegador, e não são enviados para a internet. O programa tem login e senha e faz backup. Para mais segurança, use também senha na sua conta do computador.

Posso usar no computador e no celular?

Cada aparelho guarda os próprios dados, não há sincronização automática. Você pode levar os dados de um para o outro com o backup. A chave de ativação vale para um aparelho; para ativar em outro, fale com o suporte.

Como recebo a chave de ativação?

Depois do pagamento, abra o programa, copie o código do dispositivo que aparece na tela e cole no site. A chave é gerada na hora para colar e ativar.

E se eu trocar de computador ou limpar o navegador?

Faça um backup antes (Ajustes, Baixar backup). No novo computador, ative de novo falando com o suporte e restaure o backup.

Posso levar meus dados para o Excel?

Sim. Em Ajustes você exporta o ano para um arquivo que abre no Excel.

Como falo com o suporte?

Pelo WhatsApp, no botão do site ou no número que aparece no rodapé.
